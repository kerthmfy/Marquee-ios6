# Marquee Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Marquee, a standalone iOS 6 SimKL client whose first tab is a recommendations feed, using direct SimKL APIs, Matinee's visual language, and a device-installable Theos package.

**Architecture:** A flat Objective-C/ARC app with four tabs and a Foundation-only core. Typed API clients feed a file-backed library snapshot, a persistent write outbox, and a deterministic recommendation engine. UIKit screens render from those stores and never block launch on the network. Builds use Theos with the iOS 11.4 SDK's armv7 slice and a 6.0 deployment target.

**Tech Stack:** Objective-C, ARC, UIKit, Foundation, CoreGraphics, QuartzCore, Security, SystemConfiguration, Theos, `NSURLConnection`, `NSJSONSerialization`, file-backed JSON, and a plain Foundation test harness on macOS.

**Spec:** `docs/superpowers/specs/2026-11-04-marquee-design.md` and
`docs/superpowers/specs/2026-11-05-marquee-ipad-design.md` (the iPad
supplement supersedes the original iPad compatibility-mode non-goal)

**Execution note:** Work through tasks in order. Each task ends with a build or test checkpoint and a commit. The user wants a walkthrough, so after every UI checkpoint, describe exactly what changed on screen and install it on the device before moving on.

## Global Constraints

- iOS 6.0 deployment target, armv7 only. Theos target is `iphone:clang:11.4:6.0`; `ARCHS := armv7`.
- Universal device support: iPhone stays portrait-only; iPad 2/3/4 and iPad mini on iOS 6 support portrait, landscape-left, and landscape-right. `UIDeviceFamily` is `[1, 2]`.
- From Task 8.5 onward, every task that creates or modifies UI must consume `MRLayout` and must not add fixed 320 pt dimensions. Each such task includes an iPad portrait/landscape check in its own device checkpoint. Rotation is owned per screen as it lands; Task 23 is polish, not a retrofit.
- Objective-C only, ARC. No Swift, CocoaPods, SPM, third-party libraries, or generated storyboards/nibs.
- Only iOS 6-era APIs. Banned everywhere: `NSURLSession`, `UIAlertController`, `UIStackView`, `UIVisualEffectView`, `SFSafariViewController`, `ASWebAuthenticationSession`, `WKWebView`, `UIFeedbackGenerator`, `NSLayoutAnchor`, `NSProgress`, `UIMotionEffect`, `UITableViewRowAction`, `NSURLComponents`, `NSString -containsString:`, `-stringByAddingPercentEncodingWithAllowedCharacters:`, `NSURLQueryAllowedCharacterSet`, `topLayoutGuide`, `edgesForExtendedLayout`, `automaticallyAdjustsScrollViewInsets`, `preferredContentSize`, `tintColor`, and `firstObject`.
- Use `rangeOfString:`/`NSNotFound` instead of `containsString:`. Use `MRURLBuilder`'s own percent encoder instead of `stringByAddingPercentEncodingWithAllowedCharacters:`.
- Use manual frames/autoresizing, `UIAlertView`, `UIActionSheet`, `NSURLConnection`, and custom progress views.
- Tests are Foundation-only and compile on macOS. Do not import UIKit in a test file. Test doubles and fake time live in `tests/MRTestSupport.h/m`.
- Test seams are mandatory: inject `id<MRClock>` for current time and delayed work; inject the storage root directory; inject `MRStubHTTPClient` for HTTP. Tests must never call `sleep`, `usleep`, or wait on a real wall-clock interval.
- API base is `https://api.simkl.com`; public data base is `https://data.simkl.in`; image proxy is `https://wsrv.nl`.
- Every API request carries `client_id`, `app-name=marquee`, `app-version=1.0`, `Accept: application/json`, and `User-Agent: Marquee/1.0 (iOS 6)`.
- Set `NSURLRequestReloadIgnoringLocalCacheData` on every request. Marquee manages its own HTTP cache; the system cache must not interfere.
- Auth POSTs use `application/x-www-form-urlencoded`; sync writes use `application/json`.
- Bearer tokens go only to `api.simkl.com` user endpoints. Never send a token to `data.simkl.in` or `wsrv.nl`.
- Every wsrv image URL must include `output=jpg` and `q=90`. Without `output=jpg`, iOS 6 receives WebP and shows a blank image.
- Rate limits: 10 GET/sec, 1 POST/sec, 500 requests/day for AUTH V2 free users. No `/sync/all-items` polling without `/sync/activities` and `date_from`.
- UI and model mutations run on the main thread. Network callbacks return to main. Disk writes run on a serial I/O queue. Snapshots passed to the writer are immutable values.
- Never send `allow_rewatch=yes`. V1 writes are idempotent and must not create duplicate watch sessions.
- User-facing copy says **Simkl**. Code identifiers may use `Simkl` or `simkl`.
- No SimKL PRO/VIP APIs, no rewatches, no custom lists, no scrobbling, no playback sessions.
- Persistence is file-backed JSON under `Library/Application Support/Marquee/Accounts/<accountID>/`; caches live under `Library/Caches/Marquee/`.
- All snapshots are written atomically. A library/state generation mismatch is discarded and repaired by a full sync. The outbox is never discarded because of a generation mismatch.
- The logo is parked. Use placeholder icons and launch images only.
- Write tests may use only the user's main SimKL account with one sacrificial movie and one sacrificial show. Record a baseline, never touch pre-existing library items, and restore the baseline after testing.
- Commit after every task. The workspace starts without Git; Task 1 initializes it.

## Review Focus

These are the failures most likely to hurt a real user, in order. Each is pinned by a test in the task that owns the behavior.

1. **Null and missing SimKL fields:** a sync entry with `null` timestamps, no `next_to_watch_info`, or `ids.simkl_id` instead of `ids.simkl` must normalize without crashing, inventing values, or dropping the item.
2. **Token refresh concurrency:** two authenticated requests hitting an expired token must cause one refresh, not two; a failed refresh must sign out once and must not loop.
3. **Sync correctness:** a rating-only change, a library deletion, or a failed delta fetch must never make local data lie. Deletions and rating removals disappear only after an authoritative fetch succeeds.
4. **Outbox safety:** a write retried after a kill, coalesced with a newer write, or queued for a different account must not duplicate history, apply stale state, or cross account boundaries.
5. **iOS 6 compatibility:** every image must be JPEG via wsrv, missing images must fall back to a placeholder, and no banned iOS 7+ API may slip into the build.
6. **Universal layout drift:** a screen built on a fixed 320 pt assumption must not clip, stretch, or misplace chrome on iPad portrait or landscape. Every UI task after 8.5 uses `MRLayout` and checks rotation.
